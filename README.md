
# Product App

A modern product shopping application built with **Flutter and Dart**, integrated with **Firebase** for backend services. The app features a clean user interface with a green color theme and provides screens for browsing products, managing a cart, favorites, orders, and user profiles.

##  Features

-  User Authentication
-  Home Screen
-  Product Browsing and Details
-  Product Categories
-  Add Products
-  My Products
- ️ Favorite Products
- ️ Shopping Cart
-  Checkout Screen
-  My Orders
-  User Profile
-  Custom Green Theme
-  Firebase Integration

##  Technologies Used

- **Flutter** – Cross-platform UI development
- **Dart** – Programming language
- **Firebase** – Backend and app services
- **Material Design 3** – Modern UI components

##  Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

### Installation

1. Clone the repository:

   ```bash
   https://github.com/codewithabdullah2005/product_App
   ```

2. Navigate to the project directory:

   ```bash
   cd product_App
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for your project using the FlutterFire CLI or your Firebase project configuration.

5. Run the application:

   ```bash
   flutter run
   ```

##  App Theme

The application uses a custom green color palette:

- Dark Green: `#394E1B`
- Green: `#6B8F25`
- Lime: `#9FE11D`
- Light Green: `#CCFF7C`
- Pale Green: `#F1FFCD`

These colors are defined in `lib/theme/app_colors.dart`.
